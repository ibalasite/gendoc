# DRYRUN.gen.md — Pipeline Execution Manifest 生成規則

DRYRUN 是 gendoc pipeline 的**第零步（相位邊界）**，在任何下游文件生成之前執行。
本 .gen.md 由 gendoc-flow Step 1-D 派的 gen subagent 解讀並執行：所有 bash 區塊**必須執行**，不是參考。

---

## Iron Rule：步驟 0 三段必須依序完成，缺一不可

> **Iron Law**：DRYRUN 的執行體是 `dryrun_core.py`，**不是 AI 推論**。
> AI subagent 必須執行步驟 0a → 0b → 0c 三段 bash，失敗即 `exit 1`，**禁止以 AI 估算或 grep 手算替代**。
>
> 違反此規則 = 下游所有 step 的量化 quality gate 失效。

---

## 步驟 0a：載入 gendoc 環境變數

**[強制]** 在執行任何 bash 工具前，**必須**先載入 gendoc 環境變數，取得 `GENDOC_TOOLS` 路徑：

```bash
# 載入 gendoc 環境變數（GENDOC_DIR / GENDOC_BIN / GENDOC_TEMPLATES / GENDOC_TOOLS）
source "$HOME/.claude/skills/gendoc/bin/gendoc-env.sh"

if [[ -z "$GENDOC_TOOLS" ]]; then
  echo "ERROR: GENDOC_TOOLS not set after sourcing gendoc-env.sh" >&2
  exit 1
fi

echo "[DRYRUN] Step 0a: GENDOC_TOOLS=$GENDOC_TOOLS"
```

---

## 步驟 0b：呼叫 get-upstream 讀取 8 份 Phase A 文件

**[強制]** DRYRUN 的上游檔案清單由 `templates/pipeline.json` 的 DRYRUN step `input[]` 定義（SSOT）。`get-upstream.sh` 工具負責讀取並返回 JSON。

```bash
# 呼叫 get-upstream 讀取 DRYRUN step 的 input 檔案
_UPSTREAM_JSON=$("$GENDOC_TOOLS/get-upstream.sh" --step DRYRUN --output json 2>&1)

if [[ $? -ne 0 ]]; then
  echo "ERROR: get-upstream failed for DRYRUN step" >&2
  echo "$_UPSTREAM_JSON" >&2
  exit 1
fi

# 驗證 JSON 結構
_INPUT_COUNT=$(echo "$_UPSTREAM_JSON" | python3 -c "
import json, sys
try:
    data = json.load(sys.stdin)
    inputs = data.get('inputs', {})
    print(len(inputs))
except Exception as e:
    print(f'JSON parse error: {e}', file=sys.stderr)
    sys.exit(1)
")

if [[ -z "$_INPUT_COUNT" ]] || [[ "$_INPUT_COUNT" -lt 1 ]]; then
  echo "ERROR: get-upstream returned no inputs" >&2
  exit 1
fi

echo "[DRYRUN] Step 0b: get-upstream 讀取 $_INPUT_COUNT 個 Phase A 檔案"
```

> **Iron Rule：使用 get-upstream 提供的檔案**
>
> 後續 dryrun_core.py 內部會自行重新呼叫 get-upstream 取得檔案內容（self-contained 設計）。
> 步驟 0b 的職責是**前置驗證**：確認 get-upstream 工具可用、上游檔齊全；
> **不得**改用 Read 工具或 grep 直接讀檔來繞過 get-upstream。

---

## 步驟 0c：呼叫 dryrun_core.py 計算量化值（核心執行）

**[強制]** 這是 DRYRUN 的核心執行體。**必須執行**此 bash，**禁止**以 AI 推論替代。

`dryrun_core.py` 完成以下任務：
1. 重新呼叫 get-upstream（self-contained）讀取 8 份 Phase A 檔案
2. 提取量化錨點（`extract_parameters()` 內的 7 個 metric，當前 v3.5+）
3. 依 `pipeline.json` 各 step 的 `spec_rules` 推導量化門檻
4. 寫出 `.gendoc-rules/<step>-rules.json`（每個 active step 一個）
5. 寫出 `docs/MANIFEST.md`（量化基線總表）

```bash
# 取得 state file 路徑（為 dryrun_core.py 第二位置參數）
STATE_FILE=$(ls .gendoc-state-*.json 2>/dev/null | head -1)
if [[ -z "$STATE_FILE" ]]; then
  STATE_FILE=".gendoc-state.json"
fi

if [[ ! -f "$STATE_FILE" ]]; then
  echo "ERROR: state file not found in cwd（expected .gendoc-state-*.json or .gendoc-state.json）" >&2
  exit 1
fi

# 呼叫 dryrun_core.py
echo "[DRYRUN] Step 0c: 執行 dryrun_core.py（cwd=$(pwd), state=$STATE_FILE）"
python3 "$GENDOC_TOOLS/dryrun_core.py" "$(pwd)" "$STATE_FILE" 2>&1
_DRYRUN_RC=$?

if [[ $_DRYRUN_RC -ne 0 ]]; then
  echo "ERROR: dryrun_core.py failed with rc=$_DRYRUN_RC" >&2
  exit 1
fi

echo "[DRYRUN] Step 0c: dryrun_core.py 執行完成"
```

## 步驟 0d：產出物 sanity check（執行後立即驗證）

**[強制]** 執行完 dryrun_core.py 後，必須立即驗證產出物存在性與基本完整性。任一項失敗 → `exit 1`。

```bash
# Sanity 1：docs/MANIFEST.md 存在
if [[ ! -f "docs/MANIFEST.md" ]]; then
  echo "ERROR sanity-1: docs/MANIFEST.md not generated by dryrun_core.py" >&2
  exit 1
fi

# Sanity 2：.gendoc-rules/ 目錄存在且至少 1 個 rules JSON
if [[ ! -d ".gendoc-rules" ]]; then
  echo "ERROR sanity-2: .gendoc-rules/ directory not created" >&2
  exit 1
fi

_RULES_COUNT=$(ls .gendoc-rules/*.json 2>/dev/null | wc -l | tr -d ' ')
if [[ "$_RULES_COUNT" -lt 1 ]]; then
  echo "ERROR sanity-2: .gendoc-rules/ has no rules JSON (count=$_RULES_COUNT)" >&2
  exit 1
fi

# Sanity 3：MANIFEST.md 無裸 {{PLACEHOLDER}}
_BARE_PH=$(grep -cE '\{\{[A-Z_]+\}\}' docs/MANIFEST.md 2>/dev/null || echo 0)
if [[ "$_BARE_PH" -gt 0 ]]; then
  echo "ERROR sanity-3: docs/MANIFEST.md still has $_BARE_PH bare {{PLACEHOLDER}}" >&2
  grep -nE '\{\{[A-Z_]+\}\}' docs/MANIFEST.md >&2
  exit 1
fi

# Sanity 4：所有 rules JSON 語法合法
for _RJ in .gendoc-rules/*.json; do
  if ! python3 -c "import json; json.load(open('$_RJ'))" 2>/dev/null; then
    echo "ERROR sanity-4: $_RJ has invalid JSON syntax" >&2
    exit 1
  fi
done

echo "[DRYRUN] Step 0d: sanity check passed"
echo "  - docs/MANIFEST.md: ✓"
echo "  - .gendoc-rules/: $_RULES_COUNT rules JSON"
echo "  - bare placeholder: 0"
echo "  - JSON syntax: all valid"
```

## Quality Gate（最終驗收標準，gen subagent 回報前必查）

| # | 驗收項 | 機械驗證 |
|---|---|---|
| 1 | `docs/MANIFEST.md` 存在 | `[[ -f docs/MANIFEST.md ]]` |
| 2 | `docs/MANIFEST.md` 無裸 placeholder | `grep -cE '\{\{[A-Z_]+\}\}' docs/MANIFEST.md` = 0 |
| 3 | `.gendoc-rules/` 目錄存在 | `[[ -d .gendoc-rules ]]` |
| 4 | rules JSON 數 ≥ 1 | `ls .gendoc-rules/*.json \| wc -l` ≥ 1 |
| 5 | 量化錨點均為真實值 | dryrun_core.py 內部已 validate（非 0，除非上游確實為空） |
| 6 | 所有 rules JSON 語法合法 | `for f in .gendoc-rules/*.json; do python3 -c "import json; json.load(open('$f'))"; done` |

任一項未通過，gen subagent **必須立即回報失敗**（不得自行 fallback 用 AI 推論補生成 MANIFEST.md 或 rules JSON）。

## 不允許的行為（明文禁令）

❌ **不得**用 Read 工具直接讀 EDD/PRD/ARCH 後用 AI 推論寫出量化值
❌ **不得**用 grep / awk 自己算量化錨點
❌ **不得**手寫 docs/MANIFEST.md（必須由 dryrun_core.py 生成）
❌ **不得**手寫 .gendoc-rules/*.json（必須由 dryrun_core.py 生成）
❌ **不得**因 dryrun_core.py 失敗而改用其他「替代方案」生成假產出（必須 `exit 1` 回報失敗）

唯一容許動作：執行步驟 0a → 0b → 0c → 0d 四段 bash，全部成功才算完成。
