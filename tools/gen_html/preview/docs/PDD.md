# PDD — Visual Preview Sample

> 此檔案是 `tools/gen_html/preview/` 的視覺驗證樣本，**不影響 pet/erp 任何測試環境**。
>
> 用途：
> - 驗證 A3（card / page / modal 邊界）
> - 驗證 A4（table padding / 分隔線 / thead）
> - 驗證 A5（mock 元件不可 focus，Tab 跳過）
>
> 重生方式：
> ```
> cd tools/gen_html/preview && python3 ../gen_html.py
> ```
> 產出：`tools/gen_html/preview/docs/pages/pdd.html`
